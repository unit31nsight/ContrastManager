# Contrast Manager

Минималистичная утилита для Windows 10/11: профили контрастности монитора, меню системного трея и горячие клавиши.

## Возможности

- Создание, редактирование и удаление профилей.
- Выбор профиля по умолчанию.
- Переключение из системного трея.
- Сворачивание окна в трей; выход через меню трея.
- Автозапуск для текущего пользователя Windows.
- Проверка доступности физической контрастности через DDC/CI.
- Глобальные горячие клавиши `Ctrl+Alt+1` ... `Ctrl+Alt+9` для первых девяти профилей в списке.
- Сохранение профилей в JSON в пользовательской папке конфигурации.

## Требования

- Windows 10/11.
- Python 3.11+ (рекомендуется 3.12).
- Монитор с DDC/CI, если нужна физическая регулировка контрастности. Возможно, DDC/CI нужно включить в OSD самого монитора.

## Запуск из исходников

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python run.py
```

## Горячие клавиши

`Ctrl+Alt+1` — первый профиль в списке, `Ctrl+Alt+2` — второй и так далее до девятого. Сочетания регистрируются только пока приложение запущено. Если другое приложение уже заняло сочетание, Windows может не зарегистрировать его.

## Сборка EXE

```powershell
pip install pyinstaller
pyinstaller --noconfirm --windowed --name ContrastManager run.py
```

Исполняемый файл появится в `dist/ContrastManager.exe`.

## Ограничения

DDC/CI зависит от монитора, видеокарты, кабеля, док-станции и драйверов. Проверка чтением текущего значения подтверждает, что функция отвечает, но не гарантирует, что монитор примет любое значение. Программа не меняет цифровую гамму или цветовой профиль Windows и не имитирует успешное применение.

Для нескольких мониторов приложение пытается применить одно значение ко всем дисплеям, которые обнаруживает библиотека. В будущей версии можно добавить отдельные значения для каждого монитора.
